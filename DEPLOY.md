# Send the page to Dor as a URL

## Option 1: Netlify Drop (easiest, no account needed)

1. Go to **https://app.netlify.com/drop**
2. Drag the **entire folder** `dor valentine` (with index.html, style.css, script.js, and assets inside) onto the page.
3. Wait a few seconds. You’ll get a link like: `https://something-random-123.netlify.app`
4. Copy that link and send it to Dor. He can open it on his phone or computer.

## Option 2: Vercel

1. Go to **https://vercel.com** and sign in (free).
2. Click **Add New** → **Project**.
3. Upload the `dor valentine` folder (or connect GitHub if the project is in a repo).
4. Deploy. You’ll get a link like: `https://your-project.vercel.app`
5. Send that link to Dor.

## Before you deploy

- Put your two photos in the **assets** folder as **photo1.jpg** and **photo2.jpg** (or .png and update the file names in index.html).
- Then drag/upload the whole folder so the link shows the photos too.
